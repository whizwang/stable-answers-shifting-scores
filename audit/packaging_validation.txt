Packaging and command caveats
- Preserve the flat layout of runnable Python files and CSV/JSONL inputs. compare.py and analyze_timing.py read relative to the current working directory; runner/analyze/stats mostly read relative to the script. Strict replay expects script_versions under the data root. Run reproduction commands from the repository root.
- Always pass detection.csv to analyze_feedback.py for the paper's three-test Holm family; omitting it runs a different analysis.
- The runner writes beside fliprate.py and resumes existing result files. A separate working directory alone does not isolate a new collection. Use a separate copy or checkout, keeping the published saved responses intact.
- smoke commands make real API calls. They do not belong in the no-key offline reproduction quickstart.
- Offline replay supports compatibility of the preserved source with saved histories. It does not recreate historical provider execution or independently establish the timing of preregistration/blinding.
